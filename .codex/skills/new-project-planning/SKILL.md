# New Project Planning Skill

## Goal

Create a complete beginner-friendly project plan before implementation.

## Required Steps

1. Define product idea.
2. Define target users.
3. Define core problem.
4. Define MVP.
5. Define excluded features.
6. Define user flow.
7. Define database needs.
8. Define API needs.
9. Define frontend screens.
10. Define test plan.
11. Define deployment plan.

## Output Format

1. Product summary
2. Target users
3. Core problem
4. MVP features
5. Features excluded from v1
6. User flow
7. Screen list
8. Data model overview
9. API overview
10. Development order
11. Validation checklist
12. Risks
