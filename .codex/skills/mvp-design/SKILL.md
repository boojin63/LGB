# MVP Design Skill

## Goal

Reduce a product idea into the smallest useful version that can be built and tested.

## Principles

- Solve one clear problem first.
- Avoid unnecessary features.
- Prefer manual or simple workflows in v1.
- Choose features that prove user value.
- Keep implementation realistic for a solo developer.

## Output Format

1. MVP goal
2. Must-have user actions
3. Must-have admin actions
4. Required screens
5. Required data
6. Required APIs
7. Features to postpone
8. MVP success criteria
9. Build order
