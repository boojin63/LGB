# QA Review Skill

## Goal

Verify that the implemented feature works correctly and does not break existing behavior.

## Required Checks

1. Normal user flow
2. Admin flow if applicable
3. Empty state
4. Loading state
5. Error state
6. Invalid input
7. API failure
8. Permission failure
9. Refresh behavior
10. Regression risk

## Output Format

1. Passed checks
2. Failed checks
3. Untested areas
4. Bugs found
5. Must-fix issues
6. Nice-to-have improvements
7. Release readiness
