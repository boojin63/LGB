# Fullstack Feature Build Skill

## Goal

Implement a feature safely through a professional development workflow.

## Required Steps

1. Understand the feature.
2. Inspect existing project structure.
3. Identify affected files.
4. Review database impact.
5. Review API impact.
6. Review frontend impact.
7. Implement database changes first if needed.
8. Implement backend logic.
9. Implement frontend integration.
10. Handle loading, empty, success, and error states.
11. Run or describe tests.
12. Perform QA and security review.
13. Summarize final result.

## Constraints

- Do not hardcode production data.
- Do not skip authorization.
- Do not break existing features.
- Do not add unnecessary libraries.
- Make small, reviewable changes.

## Final Output Format

1. Summary
2. Files changed
3. Database changes
4. API changes
5. Frontend changes
6. QA checklist
7. Security checklist
8. Risks
9. Next step
